# 金探｜美股市場研究儀表板

作者：施建宏（James Shih）

## 專案目的
將分散的金融資訊整理成由市場、板塊、全球市場、跨資產風險、市場廣度、產業族群到個股的研究路徑，讓每項判斷有來源、日期與查核依據。

## 我的工作
定義研究問題、規劃七個主頁與指標規則，串接資料處理、儲存與報表呈現。使用 AI 協助程式開發和異常追查，由我核對計算口徑與操作結果。

## 技術與架構
Python 擷取、整理和計算 → GitHub Actions 執行 → Neon PostgreSQL 儲存 → Power BI DirectQuery／DAX 呈現。

- 以完整交易日計算報酬與相對 SPY 強弱（RS，單位為百分點）。
- 區分交易日、成交／觀察時間與系統取得時間。
- 探索不同期間的族群領導力，個股候選則採固定二十日條件。
- 以資料有效狀態區分目前行情與歷史收盤。

## 資料來源
Alpaca SIP、State Street 官方 ETF 持倉、Yahoo 市場序列與新聞 RSS、Finviz 市場廣度、Cboe VIX。各來源負責不同內容，來源延遲與更新時間不能混為一談。

## 限制
本專案是研究輔助工具，沒有自動下單功能，不保證投資結果。DirectQuery 不代表直接連交易所或零延遲。市場短評以既定規則整理，AI 用於研發協作。

## 公開範圍
此儲存庫為作品展示版。API 金鑰、資料庫連線憑證與正式環境設定不公開。PBIX 與程式碼須完成憑證及資料授權檢查後才能加入。
