# 金探｜美股與全球市場 ETF 觀察儀表板

作者：施建宏（James Shih）

把分散的市場資訊整理為「市場 → 全球 → 板塊 → 跨資產 → 廣度 → 族群 → 個股」的觀察路徑，讓比較帶有來源、日期、口徑與有效樣本。

## 版本

說明依 2026-10-08 核對的本機正式七頁定義整理；P6「每 30 分鐘」文字與 2026-10-07 12:05 保存驗證一致。

## 我的工作

定義研究問題與七頁閱讀流程，規劃指標口徑、資料品質門檻及缺漏呈現，串接資料處理、儲存與 Power BI 視覺。使用 AI 協助程式開發與異常追查，由我核對計算口徑與操作結果。

## 技術與資料來源

Python 擷取、整理與計算 → GitHub Actions 排程 → PostgreSQL 儲存 → Power BI DirectQuery／DAX 呈現。

Alpaca SIP、State Street 官方 ETF 持倉、Yahoo 市場序列與新聞 RSS、Finviz 市場廣度、Cboe VIX。不同來源的觀察日、取得時間與資料延遲分開標示。

## 更新機制

雲端採集排程每 30 分鐘觸發；Desktop 畫面設定每 30 分鐘重新查詢。採集、驗證與畫面查詢是不同步驟，不保證同步。合格延遲成交在查詢時須通過時段、來源與 30 分鐘成交年齡檢查；超時可能退回標明日期的歷史收盤。刷新間隔不等於端到端資料延遲。

## 七頁功能

### 1. 市場總覽

從市場與風格代理看共同表現，再對照 VIX 日線與多日報酬。

先讀模式、交易日與涵蓋筆數。格狀圖等面積，不代表市值或資金流；QQQ 與 Nasdaq 綜合指數分開呈現。

### 2. 全球市場結構

用美國掛牌的國家／地區 ETF 比較相對 SPY 的表現。

可選 1／5／10／20／60 個交易日。RS 是同期報酬差，單位百分點；美元 ETF 不是當地股票指數，也不代表當地即時漲跌。

### 3. 金融板塊輪動

比較美股 11 大板塊，區分完整日報酬與合格延遲成交。

上方兩圖各有日期與涵蓋範圍。缺乏合格盤中資料時保持空白，不把舊收盤補進目前排名。

### 4. 宏觀與跨資產風險

以美元、原油、高收益債與黃金觀察跨資產背景。

DXY 是美元指數；WTI 是近月連續期貨；HYG／GLD 是 ETF。各來源日期不同，不能當成同一時點的盤中快照。

### 5. 金融市場廣度

分開閱讀 ETF 成分有效樣本與 Finviz 市場背景。

有效家數＝上漲＋下跌＋平盤。ETF 成分池不是全美股；Finviz 的母體及分母另列，觀察時間未知時仍標示 PARTIAL。

### 6. 產業與族群共振

在既有 20 檔產業 ETF 池內，觀察相對領先族群與成分參與。

期間可單選 1／5／10／20／60 日；前二依所選期間 RS 排名。進出表固定比較最近兩次成功快照的 20 日 RS。XTH／XWEB 缺口保持缺漏。

### 7. 盤中個股強弱

上半部顯示合格成分池前 20 名，下半部另列完整日候選。

上半部依合格延遲成交對前收漲跌排名，無合格樣本時可顯示標明日期的已核收盤榜。下半部使用固定 20 日資格及完整多頭條件；兩者不是同一組股票。
